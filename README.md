# 2IT – Leon Tvedten

Skolearbeid i 2IT, sortert etter fag. Hvert fag har samme oppbygging:
`Oppgaver/` for oppgaver fra skolen og `Prosjekter/` for større prosjekter.

```
2IT/
├── Brukerstøtte/
│   └── Prosjekter/
│       └── prosjekt_oppgave_UU_utforming_pdf/   Prosjektoppgave om universell utforming
├── Driftsstøtte/
│   └── Oppgaver/
│       ├── GitHub-SSH-nettverksprotokoller-oppgave/
│       ├── folder_chaos/                        Oppgave i mappestruktur
│       ├── pythonimg/                           Dockerfile med Python-program
│       └── tegninger/                           Tegninger (HTTP, himmel, elv)
└── Utvikling/
    ├── Oppgaver/                                Alle oppgaver fra skolen
    │   ├── innleveringer/                       Innleverte Python-oppgaver
    │   ├── innloggingssytem/                    Innlogging med hashing
    │   ├── oppgave-01-Leon-Tvedten/
    │   ├── oppgave-02-Leon-Tvedten/
    │   ├── oppgave-03-terminal-github-gruppe2/
    │   ├── skattejakt/                          Debug-oppgave
    │   ├── system_for_utlån_it-utstyr/
    │   └── øvingsoppgaver/                      Øvingsoppgaver (filer, lister, OOP)
    ├── Prosjekter/
    │   ├── Http_visual-explenation/             Nettside som forklarer HTTP
    │   └── mine_prosjekter/                     Egne prosjekter (aksje_marked, business_simulator)
    ├── terminal_styling/                        Hjelpemodul for terminal-styling
    └── undervisning/                            Livekoding og OOP fra timene
        ├── Live_koding/
        └── oop/
```

`terminal_styling/` og `undervisning/` må ligge i samme mappe, fordi
`undervisning/oop/oop_oppgave/oppg_3_romstasjonens_kontrollsystem/` importerer `terminal_styling`.
